# Image Url Transformer



## Requirements

This plugin requires Craft CMS 5.8.0 or later, and PHP 8.3 or later.

## Installation

You can install this plugin from the Plugin Store or with Composer.

#### From the Plugin Store

Go to the Plugin Store in your project’s Control Panel and search for “Image Url Transformer”. Then press “Install”.

#### With Composer

Open your terminal and run the following commands:

```bash
# go to the project directory
cd /path/to/my-project.test

# tell Composer to load the plugin
composer require the-web-dudes/craft-image-url-transformer

# tell Craft to install the plugin
./craft plugin/install image-url-transformer
```
